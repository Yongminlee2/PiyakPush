# 광고 붙이기 계획 (보상형 · 전면 · 배너)

앱이 정식 출시된 뒤(`1.0.3+4`) 광고를 붙이는 계획.

**가장 중요한 원칙**: 이 게임은 "천천히 생각하며 푸는 퍼즐"이다.
광고가 생각을 끊으면 사람들이 떠난다. 돈은 광고를 많이 틀어서가 아니라
**사람이 남아서** 번다. 아래 배치는 전부 그 기준으로 정했다.

---

## 1. 어디에 무엇을 넣나

### 보상형 광고 (제일 먼저, 제일 중요)

**힌트가 떨어졌을 때 "광고 보고 힌트 받기".**

지금은 힌트가 0개면 "힌트를 다 썼어요 / 새 스테이지를 깨면 1개 받아요"만
띄우고 끝난다(`_sayNoHints`). 여기에 버튼을 하나 더 둔다.

- 광고 시청 완료 → 힌트 **2개** 지급
- 붙일 자리는 이미 있다 — `SaveService.addHints(int n)`
- 하루 상한을 둔다 (예: 5회). 무제한이면 퍼즐이 성립하지 않는다

이게 **이 게임에서 유일하게 사용자가 반기는 광고**다. 막혀서 답답할 때
스스로 선택해서 보는 것이기 때문이다. 다른 보상(챕터 미리 열기 등)은
넣지 않는다 — 진행 규칙(8판 클리어)이 무너진다.

### 전면 광고 (조심해서)

**스테이지를 깨고 다음으로 넘어갈 때, 단 몇 판에 한 번만.**

| 규칙 | 값 | 이유 |
|---|---|---|
| 노출 간격 | 클리어 **3~4판마다 1회** | 매판 띄우면 게임이 아니라 광고 시청이 된다 |
| 최소 시간 간격 | 직전 광고 후 **3분 이상** | 빨리 깨는 판이 몰리면 연속으로 뜬다 |
| 절대 띄우지 않는 곳 | 판을 푸는 중 · 다시 하기 · 되돌리기 · 앱 켜자마자 · 보상형 광고 직전/직후 | 정책 위반이거나 짜증만 남는다 |
| 첫 노출 | **튜토리얼(1챕터 1~3판) 이후부터** | 시작하자마자 광고를 보면 그냥 지운다 |

전면 광고는 **미리 불러 두고**(preload), 준비가 안 됐으면 그냥 건너뛴다.
광고 때문에 다음 판으로 못 넘어가는 일이 있으면 안 된다.

### 배너 광고 (게임 화면에는 넣지 않는다)

**챕터 목록 · 스테이지 목록 · 스티커북 · 데일리 화면 아래에만.**

게임 화면에는 넣지 않는 이유가 분명하다. 지금 게임 화면은
조작 영역 276px를 고정으로 비워 두고 남는 공간에 맞춰 칸 크기를 정한다
(`kControlAreaHeight`). 여기에 배너를 끼우면 **판이 작아지고**,
조이스틱과 방향키의 화면이 달라져 `control_scheme_parity_test`와
`device_variety_test`가 깨진다. 작은 기기에서는 칸이 20px 밑으로 내려가
게임이 성립하지 않는다.

메뉴 화면들은 이미 `scrollPadding(context)`으로 아래 여백을 계산하니,
배너 높이를 그 여백에 더하면 깔끔하게 들어간다.

---

## 2. 넣기 전에 반드시 하는 일 (순서가 중요)

**이 순서를 지키지 않으면 앱이 내려간다.**

1. **개인정보처리방침 먼저 갱신** → `legal/peeppush/privacy.html`
   - 지금 방침에 "광고를 넣게 되면 이 방침을 먼저 갱신한 뒤 배포한다"고
     적어 뒀다. 그 약속대로 한다
   - 광고 제공자가 무엇을 읽는지(광고 ID 등) 명시
   - **방침을 올린 다음에** 광고가 든 빌드를 올린다
2. `legal/peeppush/index.html` · `support.html`의 "인터넷을 쓰지 않는다" 류 문구 수정
3. 콘솔 신고 4개 (전부 `store/플레이스토어-작성내용.md` 9번에 정리돼 있다)
   - 데이터 보안 → **수집함** (광고 ID, 기기 정보)
   - 콘텐츠 등급 → **광고 포함 예**
   - 앱 콘텐츠 → 광고 → **광고 포함** 선언
   - 앱 콘텐츠 → 광고 ID → **예**
4. 매니페스트에 권한 추가 (지금은 권한이 **0개**다)
   - `INTERNET`
   - `com.google.android.gms.permission.AD_ID`

**스토어 등록정보(앱 이름·설명)는 손댈 것이 없다.** 애초에 광고·인앱결제·
무료 이야기를 한 줄도 안 썼기 때문이다.

---

## 3. 어린이 관련 — 이게 제일 까다롭다

콘텐츠 등급에서 **"어린이와 성인 모두(Mixed audience)"** 로 신고해 뒀다.
그림체가 유아 친화적이라 이 판단은 맞지만, **광고를 붙이는 순간 제약이 생긴다.**

- 어린이에게는 **맞춤 광고(개인화 광고)를 보여주면 안 된다**
- 광고 내용도 어린이에게 적합한 것만 나와야 한다
- AdMob 설정에서 이 앱을 **어린이 대상 취급**으로 표시하거나,
  나이를 묻는 화면을 두고 구분해야 한다

가장 간단하고 안전한 선택은 **전부 어린이 대상으로 취급**하는 것이다.
수익은 좀 줄지만 정책 위반 위험이 없고, 나이를 묻는 화면을 만들 필요도 없다.
처음에는 이렇게 가고, 나중에 필요하면 바꾼다.

## 4. 유럽 이용자 동의 (필수)

176개국에 배포 중이라 **유럽 이용자가 들어온다.** 유럽에서는 광고를 보여주기
전에 동의를 받아야 하고, 안 받으면 정책 위반이다.

구글이 주는 동의 화면(UMP)을 붙이면 된다. 직접 만들 필요 없고,
AdMob 콘솔에서 양식을 만들어 앱에서 호출하면 유럽 이용자에게만 뜬다.
**첫 광고를 보여주기 전에** 한 번 물어본다.

---

## 5. 작업 순서

### 0단계 — 준비 (코드 작업 아님)
- AdMob 계정 만들고 앱 등록 → 앱 ID 발급
- 광고 단위 3개 만들기 (보상형 / 전면 / 배너)
- UMP 동의 양식 만들기

### 1단계 — 배관 (광고는 아직 안 보임)
- `google_mobile_ads` 패키지 추가
- 매니페스트: 권한 2개 + 앱 ID 메타데이터
- 앱 시작 때 초기화, UMP 동의 먼저 처리
- **광고 서비스 래퍼 하나**를 만든다 (`lib/services/ad_service.dart`)
  - 화면들이 AdMob을 직접 부르지 않게 한다. 나중에 광고 회사를 바꾸거나
    끄고 싶을 때 이 파일 하나만 고치면 된다
  - **인터넷이 없거나 광고가 실패해도 게임은 그대로 돌아가야 한다.**
    지금까지 이 게임은 인터넷 없이 완전히 동작했다. 그 성질을 잃으면 안 된다
- 개발 중에는 **구글이 주는 테스트 광고 ID**만 쓴다
  - 내 광고를 내가 누르면 계정이 정지된다. 실수로라도 안 되게 테스트 ID로 둔다

### 2단계 — 보상형 (여기서부터 돈이 된다)
- 힌트 없음 안내에 "광고 보고 힌트 2개 받기" 추가
- 하루 상한 적용
- 문구 13개 언어 추가

### 3단계 — 전면
- 클리어 횟수 세기 + 시간 간격 규칙
- 미리 불러 두고, 준비 안 됐으면 건너뛰기

### 4단계 — 배너
- 메뉴 4개 화면 아래에
- `scrollPadding`에 배너 높이 반영

### 5단계 — 출시
- 개인정보처리방침·공개 페이지 갱신 → **먼저 배포**
- 콘솔 신고 4개 갱신
- 테스트 ID를 **실제 광고 ID로 교체**
- 버전 올리고(`1.1.0+5` 정도) AAB 빌드
- 출시노트 13개 언어

---

## 6. 테스트에서 지킬 것

- **광고가 안 나와도 게임이 되는지**가 가장 중요하다.
  `AdService`를 가짜로 갈아 끼워, 광고가 전부 실패하는 상황에서도
  기존 테스트 224개가 그대로 통과해야 한다
- 전면 광고 규칙(몇 판마다 · 최소 간격 · 튜토리얼 제외)은
  **순수 함수로 떼어내서** 테스트한다. 화면 코드에 묻으면 검증할 수 없다
- 배너를 넣은 뒤 `system_bar_inset_test`가 여전히 통과하는지 확인

---

## 7. 현실적인 기대치

개인 개발 퍼즐 게임에 광고를 붙인다고 바로 수익이 나지는 않는다.
**보상형 힌트 하나만 잘 붙여도 전체 수익의 대부분이 거기서 나오는 경우가 많다.**
전면과 배너는 조금 보태는 정도다.

그래서 순서를 **보상형 → 전면 → 배너**로 잡았다.
1·2단계까지만 해 두고 반응을 본 다음, 3·4단계를 할지 정해도 된다.

---

## 진행 상황 (코드 작업 완료)

1~4단계를 구현했다. **남은 것은 5단계(콘솔·방침) 뿐이다.**

| 넣은 것 | 자리 |
|---|---|
| 보상형 | 힌트가 떨어졌을 때 "광고 보기" → 힌트 2개, 하루 5회까지 |
| 전면 | 스테이지 클리어 뒤. 5판까지는 안 띄우고, 이후 4판마다·최소 3분 간격 |
| 배너 | 챕터목록 · 스테이지목록 · 스티커북 · 데일리 (게임 화면에는 없음) |

**디버그 빌드는 구글 테스트 광고, 릴리스만 실제 광고 ID**를 쓴다
(`AdUnits`). 개발하다 내 광고를 눌러 계정이 정지되는 일을 막는다.

어린이 대상 취급으로 맞춤 광고를 끄고 전체 이용가 광고만 받도록 설정했다
(`AgeRestrictedTreatment.child` + `MaxAdContentRating.g`).
콘텐츠 등급을 "어린이와 성인 모두"로 신고해 둔 것과 맞춘 것이다.

### 아직 안 한 것

- **유럽 동의(UMP)** — 유럽 이용자에게 광고를 보여주기 전에 동의를 받아야 한다.
  지금은 어린이 취급으로 맞춤 광고를 끈 상태라 위험이 낮지만,
  정식으로는 AdMob 콘솔에서 동의 양식을 만들어 앱에서 호출해야 한다
- 5단계(방침 갱신 → 콘솔 신고 4개 → 버전 올려 출시)

### 출시 전 반드시

```
1. legal/peeppush/privacy.html 갱신 → 먼저 배포
2. index.html · support.html 의 "인터넷을 쓰지 않는다" 문구 수정
3. 콘솔 신고 4개 (store/플레이스토어-작성내용.md 9번)
4. 버전 올리고 AAB 빌드 (1.1.0+5 정도)
```

**2번을 빼먹기 쉽다.** 지금 공개 페이지에 "인터넷 접근 권한 자체가 없다"고
적혀 있는데, 이제는 사실이 아니다.
