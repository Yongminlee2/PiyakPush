# 출시명 · 출시노트 — 삐약푸쉬 / Peep Push

AAB를 업로드하면 콘솔이 물어보는 두 칸.

---

## 출시명 (Release name)

콘솔에만 보이는 내부 이름이다. 이용자에게는 안 보인다. 비워 두면
버전으로 자동 채워지는데, 그대로 써도 된다.

```
1.0.1 (2)
```

현재 `pubspec.yaml` 버전이 `1.0.1+2` (versionName 1.0.1, versionCode 2)이다.
**versionCode는 올릴 때마다 반드시 커져야 한다** — 같은 값이면 콘솔이 거부한다.
다음 버전을 올릴 땐 여기도 그 버전으로 바꾼다.

---

## 출시노트 (이용자에게 보이는 "새 기능" 글, 언어별 500자 제한)

**1.0.1은 버그 수정 업데이트다.** 콘솔에 바로 붙여 넣을 수 있게
`store/출시노트-콘솔붙여넣기.txt` 에 `<ko-KR>` 같은 언어 태그 형식으로 따로 적어 뒀다.
아래는 1.0.0 첫 출시용 소개 문구다 (참고용으로 남겨 둠).
등록정보와 같은 이유로 **광고·인앱결제·무료 이야기는 넣지 않았다** —
나중에 붙일 계획이라 지금 "없음"이라고 쓰면 거짓말이 된다.

콘솔은 언어를 추가한 만큼만 물어본다. 없는 언어는 영어(또는 기본 언어) 것이 보인다.
