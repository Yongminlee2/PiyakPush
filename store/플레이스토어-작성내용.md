## 6. 데이터 보안 설문 — **1.1.0부터 바뀜 (광고 도입)**

**앱이 실제로 하는 일 그대로다. 다르게 적으면 정지 사유가 된다.**
1.0.x까지는 "수집 안 함"이었지만, 1.1.0부터 광고 SDK(Google AdMob)가 들어가
아래처럼 바꿔 적어야 한다.

| 질문 | 답 |
|---|---|
| 데이터를 수집하거나 공유하나요? | **예** |
| 수집하는 데이터 유형 | **기기 또는 기타 ID** (광고 ID) · **앱 활동 → 앱 상호작용** (광고 노출·클릭) · **앱 정보 및 성능 → 비정상 종료 로그·진단** (AdMob이 수집) · **위치 → 대략적인 위치** (IP 기반) |
| 공유하나요? | **예** — 광고 제공자(Google)와 공유 |
| 목적 | **광고 또는 마케팅**, **사기 예방·보안** |
| 처리가 선택사항인가요? | **아니요** (광고를 보여 주는 데 필요) |
| 데이터가 전송 중 암호화되나요? | **예** (AdMob은 HTTPS) |
| 데이터 삭제를 요청할 수 있나요? | **예** — 기기 설정에서 광고 ID 재설정·삭제. 개발자는 수집하지 않음 |

> 이 항목은 Google이 공개한 **AdMob SDK 데이터 보안 안내**와 맞춰 적는다.
> 콘솔의 설문 화면이 이 표와 문구가 조금 다르면, AdMob 안내 쪽을 따른다.

## 9. 광고를 붙일 때 같이 고치는 것 — **1.1.0에서 처리함**

| 항목 | 상태 |
|---|---|
| 매니페스트 권한 2개 | ✅ 코드에 반영 |
| 개인정보처리방침·공개 페이지 3개 | ✅ 갱신·배포 완료 (빌드보다 먼저) |
| 데이터 보안·콘텐츠 등급 답 | ✅ 위 6·7번 표를 새 답으로 바꿔 둠 → **콘솔에 옮겨 적기만 하면 됨** |
| 콘솔 → 앱 콘텐츠 → 광고 / 광고 ID | ⬜ **콘솔에서 "예"로 바꿀 것** |

아래는 처음 붙일 때 정리했던 원래 목록이다 (인앱결제를 붙일 때 다시 쓴다).

### 원래 목록

**문구만 고치면 되는 게 아니다.** 아래를 같이 안 고치면 신고 내용과 앱이
달라져서 앱이 내려간다. 붙이는 날 이 목록을 그대로 훑을 것.

| 고칠 곳 | 무엇으로 |
|---|---|
| `AndroidManifest.xml` | `INTERNET` 권한 + `com.google.android.gms.permission.AD_ID` 권한 추가 (지금은 권한이 0개다) |
| 위 **6. 데이터 보안 설문** | 광고 SDK는 광고 식별자(AAID)·기기 정보를 수집한다 → "수집함"으로 |
| 위 **7. 콘텐츠 등급** | 광고 포함 **예** / 인앱 구매 **예** |
| 콘솔 → 앱 콘텐츠 → 광고 | "광고 포함" 선언 |
| 콘솔 → 앱 콘텐츠 → **광고 ID** | "앱에서 광고 ID를 사용하나요?" **예**로 (지금은 아니요 — SDK가 없어서 접근 자체가 불가능) |
| `legal/peeppush/privacy.html` | 광고 SDK가 무엇을 읽는지 명시. **먼저 갱신하고 나서 배포** |
| `legal/peeppush/index.html` | "인터넷 접근 권한이 없다"고 적힌 대목 |
| `legal/peeppush/support.html` | "진행 기록이 서버로 올라가나요" 답 |
| 등록정보 13개 언어 | **손댈 것 없다** — 애초에 안 썼다 |

> 순서가 중요하다. 개인정보처리방침을 **먼저** 갱신해 두고 그다음에
> 광고가 든 빌드를 올린다. 반대로 하면 심사에서 걸린다.
>
> 힌트를 보상형 광고로 주는 건 `SaveService.addHints()` 에 바로 붙는다.
> 게임 로직은 손댈 필요가 없다.
