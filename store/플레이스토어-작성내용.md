## 6. 데이터 보안 설문 — **1.1.0부터 바뀜 (광고 도입)**

**앱이 실제로 하는 일 그대로다. 다르게 적으면 정지 사유가 된다.**
1.0.x까지는 "수집 안 함"이었지만, 1.1.0부터 광고 SDK(Google AdMob)가 들어가
아래처럼 바꿔 적어야 한다.

| 질문 | 답 |
|---|---|
| 데이터를 수집하거나 공유하나요? | **예** |
| 수집하는 데이터 유형 | **기기 또는 기타 ID** (광고 ID) · **앱 활동 → 앱 상호작용** (광고 노출·클릭) · **앱 정보 및 성능 → 비정상 종료 로그·진단** (AdMob이 수집) · **위치 → 대략적인 위치** (IP 기반) |
| 공유하나요? | **예** — 광고 제공자(Google)와 공유 |
| 목적 | **광고 또는 마케팅**, **사기 예방·보안** |
| 처리가 선택사항인가요? | **아니요** (광고를 보여 주는 데 필요) |
| 데이터가 전송 중 암호화되나요? | **예** (AdMob은 HTTPS) |
| 데이터 삭제를 요청할 수 있나요? | **예** — 기기 설정에서 광고 ID 재설정·삭제. 개발자는 수집하지 않음 |

> 이 항목은 Google이 공개한 **AdMob SDK 데이터 보안 안내**와 맞춰 적는다.
> 콘솔의 설문 화면이 이 표와 문구가 조금 다르면, AdMob 안내 쪽을 따른다.

## 9. 1.1.0 올리기 — 콘솔에서 할 일 (순서대로)

**선언을 먼저, 업로드는 나중에.** 앱에 광고 ID 권한이 들어갔는데 콘솔 선언이
"아니요"로 남아 있으면 버전 검토에서 막힌다.

### ① 광고 선언
Play Console → 삐약푸쉬 → 왼쪽 **정책 및 프로그램 → 앱 콘텐츠** →
**광고** 항목의 "관리"(또는 "시작") →
**"예, 앱에 광고가 포함되어 있습니다"** → 저장.
→ 스토어에 "광고 포함" 표시가 붙는다.

### ② 광고 ID 선언
같은 **앱 콘텐츠** 화면 → **광고 ID** → "관리" →
"앱에서 광고 ID를 사용하나요?" **예** → 용도에 체크:
- **광고 또는 마케팅**
- **분석**
- **사기 방지, 보안, 규정 준수**

→ 저장.

### ③ 데이터 보안 (위 6번 표를 옮기는 곳)
**앱 콘텐츠 → 데이터 보안** → "관리"(수정) → 단계별:

1. **개요** → 다음
2. **데이터 수집 및 보안**
   - 필수 사용자 데이터 유형을 수집하거나 공유하나요? → **예**
   - 전송 중 암호화되나요? → **예**
   - 계정 만들기 방법 → **"앱에서 계정을 만들 수 없음"**(해당 칸 체크)
   - 데이터 삭제 요청 방법 → 선택 사항. 비워 두거나, 개인정보처리방침 URL
3. **데이터 유형** — 아래 4군데만 체크
   - 위치 → **대략적인 위치**
   - 앱 활동 → **앱 상호작용**
   - 앱 정보 및 성능 → **비정상 종료 로그**, **진단**
   - 기기 또는 기타 ID → **기기 또는 기타 ID**
4. **데이터 사용 및 처리** — 체크한 항목마다 눌러서 똑같이:
   - **수집됨** ✔, **공유됨** ✔
   - 임시로 처리되나요? → **아니요**
   - 필수인가요, 선택인가요? → **사용자가 이 데이터 수집을 사용 중지할 수 없음(필수)**
   - 수집 목적 → **광고 또는 마케팅**, **분석**, **사기 예방·보안·규정 준수**
   - 공유 목적 → **광고 또는 마케팅**, **사기 예방·보안·규정 준수**
5. **미리보기** 확인 → **저장**(제출)

> 콘솔 문구가 조금 다르면 Google 공식 **"AdMob 데이터 보안 섹션 안내"**
> (검색: *Google Mobile Ads SDK data disclosure*) 쪽을 따른다.

### ④ 타겟층 확인 (바꿀 것 없으면 그대로)
**앱 콘텐츠 → 타겟층 및 콘텐츠**. 만 13세 이상으로 돼 있다 — 그대로 둔다.
1.1.1부터 광고를 청소년 등급까지·맞춤 광고 허용으로 받는데, 이건 타겟이 13세 이상이라
가능한 설정이다. 13세 미만을 넣으면 가족 정책이 붙어 광고 설정을 되돌려야 한다.

### ⑤ AAB 올리기
왼쪽 **테스트 및 출시 → 프로덕션** → 오른쪽 위 **새 버전 만들기** →
- **App Bundle**: `store/업로드/app-release.aab` 끌어다 놓기 (1.1.1, 버전 코드 6)
- **출시명**: `1.1.1 (6)`
- **출시 노트**: `store/출시노트-콘솔붙여넣기.txt` 내용을 **통째로** 붙여 넣기
  (`<ko-KR>` 같은 태그째 — 콘솔이 언어별로 나눠 넣는다)

→ **다음** → 경고가 있으면 읽고 → **저장** →
왼쪽 **게시 개요** → **검토를 위해 변경사항 전송**.

### ⑥ AdMob (출시 후)
- **앱 → 삐약푸쉬 → 앱 설정 → 앱 스토어 연결**: 스토어에 올라간 앱을 검색해 연결.
  연결해야 `app-ads.txt` 확인이 돌아간다 (`https://yongminlee2.github.io/app-ads.txt`
  에 이미 올라가 있음).
- **개인정보 보호 및 메시지 → GDPR → 메시지 만들기** → 삐약푸쉬 선택 → 게시.
  유럽 이용자에게 동의 창이 뜬다. 앱 코드는 이미 준비돼 있어 앱을 다시 올릴 필요 없다.
